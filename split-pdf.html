What is split pdf?

Splitting a PDF separates a multi-page document into individual one-page PDF files. PDFora packages those page files into a ZIP archive so you can download the complete set in one step.

How to use Split PDF

  1. 1

    Upload the PDF you want to split.

  2. 2

    Start the split process.

  3. 3

    Wait while PDFora creates one PDF for each page and packages the files.

  4. 4

    Download the ZIP archive and extract it on your device.

Why use this tool?

Individual pages are easier to route, rename, upload separately, or archive when a full document is not needed. Splitting also gives you page-level files without converting the page content into images.

How PDFora works

PDFora validates the selected files and options, processes the task locally inside your browser, and creates the download on your device. Document contents are not sent to PDFora servers.

Common ways to use Split PDF

  • Separate a scanned packet into individual records
  • Create one-page files for separate uploads
  • Archive or rename pages independently
  • Share only selected page files after splitting locally

Tips for better results

  • Use Extract PDF Pages instead if you only need a few selected pages in one new PDF.
  • Use Delete PDF Pages if your goal is simply to remove unwanted pages.
  • The output ZIP can contain many files, so check your device has enough free storage.
  • Keep the original PDF until you have checked the split files.

Frequently asked questions

What does the ZIP contain?

It contains one PDF file for each page in the original document, named in page order.

Will splitting reduce page quality?

The pages are copied into separate PDFs without rasterizing them, so this operation is not an image-quality conversion.

Can I split only a range?

This tool exports every page. Use Extract PDF Pages when you want only selected pages.

Is there a page limit?

Yes. The current processing limit is 500 pages per PDF.
