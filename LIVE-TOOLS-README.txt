BATCH PROCESSING
Watermark, page numbers, protect/unlock, Office conversions and OCR accept up to 10 compatible files in one run. Multiple outputs are returned in a ZIP. Interactive Edit PDF and Sign PDF are intentionally one-document workflows so the user can visually review placement before export.

EDIT PDF
Supports adding text, images/logos, highlights, whiteout blocks and freehand drawings. It creates a new output PDF and preserves the original. Existing embedded PDF text is not guaranteed to be directly editable because PDFs can contain scans, outlined fonts, signatures or complex object structures.

OFFICE/OCR NOTE
Office conversions are practical browser conversions. Very complex Word/Excel/PowerPoint layouts, embedded media, SmartArt, unusual fonts or scanned content can produce layout differences. OCR creates a searchable PDF and quality depends on scan quality and language selection. Always review important outputs.
