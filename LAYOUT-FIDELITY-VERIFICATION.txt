Important conversion behavior
- Preserve-layout mode prioritizes visual fidelity. In Word/Excel/PowerPoint, a PDF page is represented primarily as a page/slide/worksheet image so the visual layout stays intact.
- Editable mode prioritizes native editable text/cells. Complex PDF layout can reflow because PDF is a fixed-position format and Office formats are flow/structure-based.
- A browser-only converter cannot guarantee both pixel-perfect layout and fully editable native Office objects for every PDF, especially scans, embedded fonts, charts, SmartArt and unusual PDF structures.
