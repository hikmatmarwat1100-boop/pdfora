A practical browser PDF editor

Use Edit PDF when you need to add information, place a logo or image, highlight content, cover outdated text with whiteout, or draw annotations. The original file is never overwritten.

What this editor supports

  • Add new text at any position.
  • Add PNG or JPG images and logos.
  • Highlight or whiteout selected areas.
  • Draw freehand notes and marks.
  • Export a new edited PDF after reviewing the changes.

Existing PDF text

PDFs are not structured like Word documents. This editor can place new text and cover old content, but it does not promise direct editing of every existing embedded text object, especially in scans, outlined fonts, signed PDFs or complex generated documents.
