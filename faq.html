Frequently asked questions

Questions about PDFora and browser-based PDF tools

Clear answers about file handling, privacy, conversions, quality, passwords, signatures, browser limits, advertising, and responsible use.

Does PDFora upload my document to an application server?

For supported document workflows, PDFora is designed to process the selected file in the browser on the device. That is different from a traditional upload-process-download service where the document must be sent to an application server for the operation. The website still uses normal web hosting, so technical request information needed to deliver pages, prevent abuse, and operate the site can be processed by hosting infrastructure. See the Privacy Policy for the distinction between document contents and ordinary website data.

Do I need an account before using the tools?

No account is required for the public tools described on the site. You can open a tool, choose a compatible file, process it, review the result, and save the new file. If the service changes in the future, documentation and privacy information should be updated to match the live behavior.

Does local processing mean every file will work?

No. Browser-based processing has practical limits. Very large PDFs, high-resolution scans, complex Office documents, unusual fonts, encryption, damaged files, or limited device memory can cause slower processing or failure. A desktop application can sometimes handle a file that is too demanding for a browser tab.

Why can a converted Word, Excel, or PowerPoint file look different?

PDF is a fixed-layout format, while Word, Excel, and PowerPoint use editable document models. Converting between them requires reconstructing text flow, tables, slide objects, fonts, and page structure. Simple files usually behave better than complex layouts. Always review headings, page breaks, tables, charts, images, and special characters before relying on a converted file.

Can PDF to Word make a scan fully editable?

A scan is usually an image of text rather than actual PDF text. OCR may be required to recognize characters first. OCR can make a scan more searchable or editable, but recognition is not perfect. Names, numbers, dates, and other important values should be checked against the original page.

Why did my compressed PDF not become much smaller?

Some PDFs are already optimized. Text and vector graphics can take relatively little space, while photographs and scans usually account for more. If the file has already been compressed, further reduction may save little space or require visible image-quality loss. Keep the original and compare representative pages before sharing the smaller copy.

Is JPG or PNG better when converting PDF pages to images?

JPG is often smaller for photographs and scans because it uses lossy compression. PNG is often better for screenshots, diagrams, line art, and text-heavy graphics where crisp edges matter. PNG can be much larger for photographic content. The best choice depends on the page and the destination.

Does converting a PDF page to an image keep selectable text?

No. A rendered JPG or PNG represents the appearance as pixels. Searchable text, links, form fields, and vector objects do not remain interactive in the image. If editability or searchability matters, use a document or OCR workflow instead.

What is the difference between whiteout and real redaction?

Whiteout visually covers content with a shape. It should not be assumed to permanently remove the underlying text or data from the PDF. True redaction is a security-sensitive process that removes the protected information from the file structure. Do not use a simple white rectangle when legal, privacy, or compliance requirements demand permanent redaction.

Is a drawn or typed signature a digital signature?

Not necessarily. A visual signature is a mark placed on a page. A certificate-based digital signature can include cryptographic validation and identity information. Some organizations accept a visual signature; others require an approved electronic-signature service or certificate. Confirm the recipient’s requirement before signing an important document.

What does Protect PDF actually protect?

Password encryption can prevent someone without the password from casually opening a compatible PDF. It does not prevent an authorized viewer from taking screenshots, sharing the password, or copying information after opening the file. Use strong unique passwords and follow any security rules required by your organization.

Can Unlock PDF open a file when I do not know the password?

No. The Unlock PDF workflow is intended for files you are authorized to access when you already know the current password and need an unencrypted working copy. It does not recover unknown passwords or provide access without the current password.

Will merging or reordering pages preserve every advanced PDF feature?

Page operations are useful for ordinary documents, but complex features such as signatures, forms, bookmarks, embedded attachments, or specialized metadata can require extra review. Changing a signed document can also affect signature validity. Keep the source file and verify the exported result.

Why do browser tools sometimes run out of memory?

A browser tab has finite memory. Large scans can require significant working memory because pages may need to be decoded into full-resolution images before a new file is produced. Close unnecessary tabs, work on a smaller file, reduce image dimensions when appropriate, or split a large document into smaller sections.

Can I use PDFora for confidential or regulated documents?

The suitability of any tool depends on your organization’s rules, the sensitivity of the document, and the legal or regulatory requirements that apply to you. Browser-based local processing can reduce some data-transfer concerns, but it does not replace an organization’s security policy, records rules, legal review, or approved software requirements.

Does PDFora keep my original file unchanged?

The intended workflow is to create a new output rather than overwrite the source on your device. Keep the original until you have opened and verified the exported result. This is especially important for contracts, applications, records, and documents that would be difficult to recreate.

Why should I review the result after every conversion?

File formats represent content differently, and no general-purpose conversion can guarantee perfect output for every document. A quick review catches missing characters, clipped text, unexpected page breaks, soft images, incorrect OCR, or a page-order mistake before the file is sent to someone else.

Does PDFora use advertising?

The website may use advertising to support operation of the service. Advertising should remain distinguishable from tool controls, file results, and download actions. Where advertising technology uses cookies or similar storage, relevant information is provided in the Privacy Policy and Cookie Policy.

Why might I see a consent message?

Privacy rules differ by region. Where consent is required for advertising or related technologies, an appropriate consent mechanism may be shown. The available choices and the effect on advertising can depend on location and applicable requirements.

How can I report a problem or incorrect explanation?

Use the Contact page. Include the tool name, what you expected, what happened, your browser and device type, and the approximate file size or page count. Avoid emailing sensitive documents as a first step. A non-confidential sample with similar characteristics is safer when a sample is necessary.
